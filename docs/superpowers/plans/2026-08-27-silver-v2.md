# AdStream Silver v2 Implementation Plan

Replace legacy synthetic Silver with a canonical RTB-aware, idempotent,
backend-independent Silver layer.

## Task 1 — Transformer

Files:
- `src/processing/silver_transformer.py`
- `tests/test_silver_v2_transformer.py`

Build and test:
- deterministic event_id
- preserve repeated source_bid_id at different timestamps
- canonical column names
- decimal CPM economics
- VALID/WARNING/INVALID quality classification
- quarantine invalid rows
- preserve nullable clicked semantics

## Task 2 — Storage

- `src/storage/silver.py`
- `tests/test_silver_storage_backend.py`

- Iceberg Silver backend

## Task 3 — Ingestion

- `tests/test_silver_ingestion_v2.py`
